# FIRE CARE

시설설비 점검자가 모바일에서 체크리스트 기반 점검을 수행하고, Gemini 사진 분석과 자동 보고서 생성으로 현장 업무를 보조하는 앱입니다.

[Repository](https://github.com/rnwjdgus03/fire-care) · [Presentation](../assets/fire-care-overview.pptx) · [Profile](../README.md)

## Overview

- React Native와 Expo로 설비 등록, 점검, 사진 촬영, 결과 저장 흐름을 구현했습니다.
- 16개 설비 유형과 137개 점검 항목을 PostgreSQL의 마스터 데이터로 관리합니다.
- Gemini가 선택한 설비와 사진 속 설비가 일치하는지 먼저 확인하고, 불일치하면 저장을 차단합니다.
- 사진으로 확인할 수 없는 점검 항목은 AI가 임의로 판정하지 않고 작업자의 직접 확인 대상으로 남깁니다.
- 여러 작업자가 같은 건물의 설비와 점검 결과를 공유할 수 있도록 서버 DB 기반 동기화를 구현했습니다.
- 건물 전체 점검 결과와 인증사진을 묶어 HTML 보고서를 만들고 이메일로 전송합니다.

## Safety and Reliability

| Problem | Response |
|---|---|
| 선택 설비와 사진 속 설비가 다름 | Gemini의 설비 일치 확인 후 불일치 시 저장 차단 |
| 어둡거나 흐린 사진 | 사진 품질 검사 후 재촬영 안내 |
| 사진으로 확인할 수 없는 항목 | `직접 확인`으로 분리하고 확인 전 저장 차단 |
| 여러 작업자의 데이터 불일치 | PostgreSQL 서버 DB에서 회사 단위로 데이터 동기화 |

AI 분석 결과는 점검 보조 정보이며, 법정 자체점검 완료나 적합 판정을 의미하지 않습니다. 현장 최종 판단은 자격과 권한을 갖춘 점검자가 수행합니다.
